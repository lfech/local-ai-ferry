# Local AI Ferry

`loaf` prepares Ollama models, serves them through Open WebUI using Docker
Compose, and transfers deployments to offline Debian hosts.

After installing the wheel into a virtual environment, run
`loaf link-docker-project` from your deployment directory and use
`loaf --help` for available commands. Host setup and full deployment
backups use the source checkout.

[Project documentation](https://github.com/lfech/local-ai-ferry)
